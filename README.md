# MAISON. — MAKE ROOM. | Architectural Furniture & Objects

> Sculptural furniture and architectural objects for how you live. Modernist design engineered for longevity.

---

## 🪑 Project Overview
**MAISON.** is a digital showroom and brand experience for architectural furniture and sculptural home objects. Designed with modernist typography, high-craft editorial grids, and interactive product switchers.

### Key Features
- **Dynamic Finish & Colorway Selector**: Interactive swatches allowing users to preview products like the *LB Chair* in Electric Cobalt, Alpine Moss, Burnt Sienna, and Anthracite.
- **Editorial Presentation Grids**: High-impact editorial showcase balancing bold form typography (*Syne*, *Space Grotesk*, and *Inter*) with negative space.
- **System Catalog**: Interactive product drawer with complete dimensions, material specs, and lead times for seating, tables, lighting, and textiles.
- **Micro-Interactions & Motion**: Fluid scroll progress bar, staggered reveals, and smooth responsive drawer states.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or run a lightweight local web server:

```bash
# Python 3
python -m http.server 8000

# or Node.js
npx serve .
```

Visit `http://localhost:8000` to view the collection.
